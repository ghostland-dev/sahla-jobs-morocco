# Sahla Jobs

Job board for Morocco (Arabic UI).

## Features

- Job listings and details
- Companies
- Candidate profile

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/sahla-jobs-morocco.git
cd sahla-jobs-morocco
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
